# Eco Points Recycling Track App

## Overview

A simple, console-based Java app that tracks each household's recycling activities and calculates the eco points each household earns. 

## Features

- Register household
- Log recycling event
- Display households
- Display household recycling events
- Generate and save reports

## Installation

1. Download the code to your local machine.
2. Compile the source files:
    
    ```bash
    javac com/app/*.java com/utils/*.java    
    ``` 

## Usage

Start the application:

```bash
java com.app.EcoPointsRecyclingTracker   
```

## Technologies Used

- Java
